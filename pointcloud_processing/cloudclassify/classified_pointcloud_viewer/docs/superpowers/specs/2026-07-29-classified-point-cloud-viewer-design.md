# 分类点云查看器设计

## 目标

为带表头的分类点云 `.txt` 文件提供 Open3D 交互式可视化。默认显示文件原始 RGB；用户可切换为按 `class_id` 着色，并调整点大小。

## 输入与启动

- 默认输入：项目根目录的 `cropped_point_cloud_classified.txt`。
- 可选位置参数：指定其他同格式 `.txt` 文件。
- 输入必须包含 `x,y,z,r,g,b,class_id` 列；RGB 按 0--255 值归一化为 Open3D 所需的 0--1。

## 交互

- `0`：显示原始 RGB（默认模式）。
- `1`：显示由 `class_id` 决定的稳定类别颜色。
- `+` 或 `=`：增大点大小。
- `-` 或 `_`：减小点大小，最小为 1。
- `R`：重置视角；`Q` 或 `Esc`：关闭窗口。

颜色模式切换不改变点大小或相机视角。类别颜色由确定性调色规则生成，同一类别在同次及不同次运行中保持一致。

## 上次状态恢复

- 状态文件为项目根目录的 `point_cloud_viewer_state.json`。
- 状态按输入 `.txt` 的解析后绝对路径分别保存，因此不同点云不会互相覆盖显示设置。
- 窗口关闭后保存当前 `color_mode`、`point_size` 和 Open3D 相机参数（旋转、缩放、平移对应的针孔相机内外参）。
- 启动同一输入文件时，在添加点云后恢复颜色模式、点大小和相机视角。
- 状态文件不存在、JSON 损坏、字段无效或相机参数无法应用时，忽略无效部分并使用对应默认值；不得阻止点云窗口打开。

## 实现边界

新增单一 Python 脚本，数据读取和颜色生成保持为可独立测试的函数；仅在运行窗口时导入 Open3D，以便无 GUI 环境仍能运行数据单元测试。窗口使用 `VisualizerWithKeyCallback` 注册键盘回调，并在 `try/finally` 中销毁窗口。

## 验证

- 单元测试：CSV 读取、RGB 归一化、类别颜色的稳定性、缺失必需列时的报错，以及状态文件的按路径保存、恢复和损坏回退。
- 语法检查：在 `ms_pointcloud_midterm` Conda 环境中编译脚本和测试。
- GUI 手动检查：确认 `0`、`1`、`+`、`-` 的实际窗口行为；自动化测试不代替此步骤。
