# 可辨识性加权配准 vs 等权配准（消融实验）

**目的**：为专利《一种基于几何和光谱可辨识性加权的多光谱点云配准方法》的实施例三提供真实数据——
验证把"几何 + 光谱可辨识性"写成逐点权重并引入配准代价，相比"完全相同的流程但不加权"是否有改善。

**脚本**：`identifiability_weighted.py`　**输出**：`identifiability_weighted.json`

## 1. 权重定义

参考旋转轴 `(0.0009, 1.2505)`（来自既有 turntable 分析），`r_i = sqrt((x−0.0009)² + (y−1.2505)²)`：

| 项 | 定义 | 物理含义 |
|---|---|---|
| 几何可辨识性量度 | `g_i = clip((r_i − 0.005)/0.015, 0, 1)` | 离轴越远，绕轴旋转相同角度的位移越大 → 越可区分 |
| 光谱可辨识性量度 | `s_i = 1/(1+exp(−(NDVI_i − 0.5)/0.1))`，NDVI 用 650/800 nm | 材质沿周向越均一，光谱越不随旋转角变化 → 越不可辨识 |
| **可辨识性权重** | **`w_i = g_i · s_i`** | 两项联合判定 |

权重分布（已被"几何+光谱"双判据过滤后）：

|---|---|---|---|---|---|

## 2. 配准流程（两臂完全相同，只有 w 不同）

- 对应：每源点取 K=10 个几何近邻，代价 `cost = w_i·[(d/d_max)² + λ·(SAM/Δ)²]`，取最小者（λ=1，d_max=0.015 m，Δ=10°）
- 位姿：由对应点集做**加权 SVD**（加权 Umeyama），权重 `w_i · 1/(1+(e/c)²)`（柯西型稳健核，e 为合并残差，c=1）
- 迭代 60 次；初值两个：`cache/registration.npz` 的几何粗配准解 与 恒等变换
- 择优：**可辨识点集上 fit@5mm 最大**（同专利权利要求 8）
- 消融对照：`w_i ≡ 1`

与原 M_joint（`experiment_rawdata.py:joint_icp`）的三处差异：① 代价乘逐点权重；② 加权 SVD 代替 open3d 点到面；③ 全分辨率迭代（原为 3 mm 下采样）。

## 4. 结论（含不利结果）

1. **在可辨识点集口径上，加权有效**：fit@5mm 由 0.4493 → 0.4709（**+0.0215，相对 +4.8%**），fit@10mm +0.0227，rmse@20mm 减少 0.26 mm，互近邻 +0.0047。四个视角逐一对比为 0.4298/0.4774/0.4862/0.4769/0.4842（加权）对 0.4115/0.4615/0.4112/0.4755/0.4870（等权），**4/5 视角改善（+0.0014～+0.0750）、1 个视角（300°路）轻微变差（−0.0028，该视角两臂均收敛到零转角解）**。
2. **在全部点口径上，加权反而变差**（fit@5mm −0.0381、rmse +0.50 mm、互近邻 −0.0118）。这是**必须并列报告的不利结果**；其解释与既有发现一致：全部点口径被无信息的近轴旋转不变结构主导，降权后位姿更偏向叶片，该口径的"免费匹配"得分自然下降。换言之，**两个口径给出的结论相反，恰好构成"可辨识性"论点本身的直接证据**。
3. **机理证据（本实验最强的支持）**：加权臂的解与"可辨识点集几何最优角"的平均偏差为 **6.7°**，小于等权臂的 **9.4°**，且**五个视角全部更靠近**（10.7<12.6、3.5<5.1、18.9<25.9、0.3<3.3、0.0<0.1）。说明权重确实把位姿解拉向可辨识子集的最优，而非偶然。
4. **与既有方法比**：在可辨识点集口径的 fit@5mm 上，两臂（0.4709 / 0.4493）均超过四个既有对照的最好值（M_cripped 0.4378）；互近邻超过 M_cripped/M_ref/M_joint 但低于 identity；**SAM 仍以 identity 最优**（8.10° vs 11.01°），与既有"SAM 偏好不动"的结论一致。
5. **光谱项未获益**：加权臂 SAM 在可辨识点集上略升（+0.06°），说明本实验中权重只改善了**几何定位**，没有改善光谱一致性；这与既有判据冲突检测（corr(SAM, 旋转角)≈+0.94）指向同一现象。

## 5. 不确定性与局限（务必随结论一并引用）

1. **无真值位姿**：转台轴未标定、实际转角未记录，φ* 与报告的转动/平移量都只是估计与参考，**不可解释为绝对外参误差**。择优口径本身用可辨识点集 fit@5mm，与报告指标部分同源（两臂一致，故消融仍公平）。
2. **与 M_joint 非同一实现**：本实验全分辨率迭代 + 加权 SVD，原 M_joint 为 3 mm 下采样 + open3d 点到面。因此"本实验两臂 vs M_joint"不是纯算法消融，只有**两臂之间**是严格消融。
3. **样本量 n=5**：5 个视角、单次运行（无随机性），不能做显著性检验；1 个视角（300°）两臂几乎相同（该视角参考最优角即为 0°）。
4. **只有 1 组数据**：全部结论来自单株盆栽植被的 6 视角扫描，未在其他对象、其他分辨率、其他波段区间上验证。
5. **权重形式未经调参**：r0/r1/NDVI 阈值与过渡宽度均沿用既有分析取值，未做敏感性分析；λ、K、d_max 同样沿用 M_joint 取值。
6. **未解决的冲突**：几何判据（fit@5mm）支持"确实发生了大角度旋转"，而光谱判据与互近邻判据仍偏好恒等解；本实验没有解决这一冲突，只是把它量化了。
