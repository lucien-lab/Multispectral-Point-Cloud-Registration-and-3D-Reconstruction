# 几何配准 / 几何+RGB 配准 / 几何+多光谱配准 优劣分析（更正版 v2）

> **本版更正 v1 的两处问题**：① v1 表 6 中 RGB 臂的 SAM 用的是 RGB 自身 3 个波段，而几何/多光谱臂
> 用的是 500-800 nm，跨臂比较不成立；② v1 未考虑 RANSAC 随机采样造成的运行间波动，因而把
> 0.000-0.01 量级的差异当作结论。本版统一在 500-800 nm 与 450-900 nm 上评价所有臂，
> 并给出重复性波动用于判定差异是否可信。

**协议**：20260201 六视角转台扫描（0/60/120/180/240/300 度），语义分割后的植株+花盆点云，
光谱 2048 波段（276.8-1091.7 nm）。三臂除光谱描述子外代码路径完全一致：
体素 3 mm + FPFH(2 cm) → 描述子 RANSAC → 位姿细化（光谱臂代价 (d/d_max)^2 + lambda*(SAM/Delta)^2，
lambda=1、K=10、d_max=0.015 m、Delta=10 度、60 次迭代；多初值 {{融合 RANSAC, 单位阵}}）。
评价：5 个非基准视角平均。两条择优规则：
**R1（现有）**= 候选满足 fit@20mm >= 0.90 后取 SAM 最小；**R2（几何优先）**= 取 fit@5mm 最大候选。
数值来源：which_metric_best.json、repeatability.json、pickrule_check.json、
metrics_analysis.json、identifiability_weighted.json、invariance.json。

## 一、直接回答：哪些指标体现「几何+多光谱」最好？

**结论：只有「统一口径的光谱一致性（SAM）」在两规则下都指向多光谱臂，且幅度很小；
所有拟合优度类指标上多光谱臂从来不是最优。**

| 指标 | 最优臂（R1 光谱优先） | 最优臂（R2 几何优先） | C 是否两规则均最优 |
|---|---|---|---|
| fit@5mm | A 几何 | B 几何+RGB | — |
| fit@10mm | A 几何 | B 几何+RGB | — |
| fit@20mm | A 几何 | B 几何+RGB | — |
| rmse@20mm | A 几何 | B 几何+RGB | — |
| fit_mutual@20mm | C 几何+多光谱 | A 几何 | — |
| sam500_800 | C 几何+多光谱 | C 几何+多光谱 | **是** |
| sam450_900 | C 几何+多光谱 | C 几何+多光谱 | **是** |

幅度：
- R2（几何优先）下，SAM(500-800) 为 A 10.91 度 / B 10.98 度 / C 10.85 度，
  C 对 A 的优势只有 **0.05 度**，与运行间波动同量级；
- R1（光谱优先）下，C 的优势扩大到 1.83 度，
  但代价是 3/5 帧选中「几乎不旋转」的单位阵候选（旋转角 23.7/16.3/4.8 度），**该优势是退化解换来的**。

**⚠ 上述 SAM 优势存在循环论证**：SAM 是 C 臂（几何+多光谱）目标函数的一项
（cost = (d/d_max)^2 + lambda*(SAM/Delta)^2），因此用它横向评价 C 是自证。
证据有两条：① 改用 R2（SAM 不参与选解）后 C 的优势从 1.83 度缩到 0.05 度；
② **留出波段检验**（评价波段取 450-495 nm 与 805-900 nm，与 A/B/C 的优化波段全部不相交）后，
三臂在留出波段上几乎完全相同——C 不再占优（详见第十节）。

**真正体现多光谱增量的是「能力型 + 消融型」指标，不是三方式配准结果指标**：

| 证据 | 数值 | 说明 |
|---|---|---|
| 描述子判别比 | RGB 2.92 / 500-800 nm **4.08** | 配准前即可测，不依赖配准结果 |
| 能否算 NDVI | NDVI Cohen d=4.01 / 最佳可见光代理 NGRDI 3.05 | 决定能否构造可辨识性权重 |
| **可辨识性加权消融** | 可辨识点集 fit@5mm **0.4493 → 0.4709（+0.0215）** | 是运行间波动（0.001-0.004）的 **5-20 倍**，全部实验中唯一远超噪声的多光谱增益 |
| 同上，位姿偏差 | 与独立 1-DOF 参考角平均偏差 **9.4 度 → 6.7 度** | 权重把位姿拉向可辨识子集的最优 |
| SAM 的独立监测能力 | SAM-旋转 r=+0.940、SAM-平移 r=+0.934 | 几何量给不出的独立信号（fit-rmse 仅 -0.855，属同源） |

## 二、重复性波动（判定差异是否可信的前提）

同一臂重复运行（仅 RANSAC 随机采样不同），5 帧平均的波动幅度：

| 臂 | fit@5mm | fit@10mm | fit@20mm | rmse@20mm |
|---|---|---|---|---|
| A 几何（3 次） | +-0.0010 | +-0.0026 | +-0.0002 | +-0.02 mm |
| B 几何+RGB（2 次） | +-0.0043 | +-0.0006 | +-0.0003 | +-0.01 mm |

即：几何指标的臂间差异需大于约 0.004（fit@5mm）才可讨论；R2 下 A/B/C 的 fit@5mm 差异为
0.5014 / 0.5051 / 0.4950，B-A = 0.0037（在噪声内），B-C = 0.0100（约 2 倍噪声，勉强可分）。
而 fit@10mm 上 B-A = 0.0105，是噪声（+-0.0026）的 4 倍，**这一项是可信差异**。

## 三、R2（几何优先，公平比较）下的三臂对比

| 臂 | fit@5mm↑ | fit@10mm↑ | fit@20mm↑ | rmse@20mm↓ | 互为最近邻↑ | SAM(500–800)↓ | SAM(450–900)↓ |
|---|---|---|---|---|---|---|---|
| A 几何 | 0.5014 | 0.8369 | 0.9828 | 7.05 | 0.1473 | 10.91 | 18.69 |
| B 几何+RGB | 0.5051 | 0.8474 | 0.9848 | 6.87 | 0.1292 | 10.98 | 19.01 |
| C 几何+多光谱 | 0.4950 | 0.8382 | 0.9828 | 6.99 | 0.1347 | 10.85 | 18.65 |

解读：**几何类指标上 RGB 臂略优**（fit@10mm 高 0.0105、fit@20mm 高 0.0020、rmse 低 0.18 mm，均超出运行波动），
多光谱臂与纯几何臂基本持平；**光谱一致性上三臂几乎重合**（SAM(500-800) 10.85-10.98 度），
多光谱臂仅名义最优（领先 0.05 度）。互为最近邻以纯几何臂最高。

## 四、R1（光谱优先，现有规则）下的三臂对比

| 臂 | fit@5mm↑ | fit@10mm↑ | fit@20mm↑ | rmse@20mm↓ | 互为最近邻↑ | SAM(500–800)↓ | SAM(450–900)↓ |
|---|---|---|---|---|---|---|---|
| A 几何 | 0.5014 | 0.8369 | 0.9828 | 7.05 | 0.1473 | 10.91 | 18.69 |
| B 几何+RGB | 0.4912 | 0.8111 | 0.9660 | 7.13 | 0.1571 | 9.74 | 18.01 |
| C 几何+多光谱 | 0.4628 | 0.7835 | 0.9602 | 7.48 | 0.1655 | 9.08 | 17.87 |

解读：呈现清晰的**单调权衡**——光谱一致性随光谱信息增加而改善
（SAM(500-800)：A 10.91 度 → B 9.74 度 → C 9.08 度），
拟合优度与互为最近邻随之下降（fit@5mm：0.5014 → 0.4912 → 0.4628）。
即 R1 与 R2 展示的是同一权衡的两端：规则决定你看到「更低的谱角」还是「更高的几何重叠」。

## 六、逐方式优劣（更正后）

### A 几何配准

**优点**
1. 最快最省：单帧 1.5 s（多光谱臂 5.6 s 的 27%）；不需要辐射定标、暗/白参考与入射角校正，预处理链最短。
2. 对辐射变化免疫：位姿只由坐标决定，曝光/白平衡/反射率漂移不影响结果。
3. 在 R2 规则下几何指标与多光谱臂持平（fit@5mm 0.5014 对 0.4950），互为最近邻为三臂最高（0.1473）。
4. 硬件门槛最低。

**缺点**
1. 低阈值下与「不配准」不可分：恒等变换 fit@5mm = 0.5133 > 本臂 0.50 左右；须靠 fit@20mm 才可区分（0.9828 对恒等 0.9029）。
2. 无任何物性信息：平面滑移、重复/自相似结构、镜像歧义、同形不同材质四类歧义原理上无解。
3. 无法输出位姿可信度，只能在失败时静默给出一个数。
4. 拟合优度被「免费匹配」抬高：近轴近似不变结构占 27%-34%（0 度与 60 度间有 1081 点 <= 1 um 重合，占 60 度帧 24%，
   NDVI 中位 0.17 对叶片 0.87）；全部点口径 fit@5mm 0.5228 → 仅取可辨识子集降至 0.4493（差 0.073）。

### B 几何+RGB 配准

**优点**
1. 成本最低、数据量最小（3 通道）；单帧 3.0 s；普通彩色相机即可。
2. **拟合优度类指标为三臂最优**：fit@10mm 0.8474（+0.0105 对 A，超出运行波动 4 倍）、
   fit@20mm 0.9848、rmse@20mm 6.87 mm（最低）。
3. R1 规则下其 SAM(500-800) = 9.74 度 **优于纯几何臂**（10.91 度），
   说明 RGB 的光谱项确有轻微收益（约 1.17 度）。
4. 判别比 2.92，优于「堆维度」方案（可见光窄带 634 维 1.31、全波段 2048 维 1.08）。

**缺点**
1. 光谱收益有限：R2 下与几何/多光谱臂持平（10.98 度 对 10.91/10.85 度），
   R1 下收益约 1.17 度，仅为多光谱臂（1.83 度）的一半。
2. **缺 800 nm，无法计算 NDVI**：NDVI 的 Cohen d = 4.01，最佳可见光代理 NGRDI 仅 3.05、GCC 2.34、ExG 1.85，
   故无法实施逐点可辨识性加权，也无法输出位姿可辨识性判定。
3. 宽波段且经白平衡/曝光处理，跨视角辐射一致性差；白平衡不一致会直接变成光谱项误差。
4. 判别比仍低于多光谱（2.92 < 4.08），邻点光谱角 9.43 度（多光谱仅 4.62 度）。

### C 几何+多光谱配准（500-800 nm，755 维 → PCA 12 维）

**优点**
1. 判别比最高，是唯一能稳定支撑光谱项的描述子：4.08（邻点 SAM 4.62 度 对随机对 18.86 度）。
2. **唯一能算 NDVI（d=4.01）并实施逐点可辨识性加权与位姿可辨识性判定**；消融证据：
   可辨识点集 fit@5mm 0.4493 → 0.4709（+0.0215，为运行波动的 5-20 倍），
   位姿与独立 1-DOF 参考角平均偏差 9.4 度 → 6.7 度。
3. 统一口径 SAM 在两规则下均名义最优（R2 10.85 度 / R1 9.08 度），且 R1 下相对纯几何改善 1.83 度。
4. 提供独立于几何的误差监测信号：SAM-旋转 r=+0.940、SAM-平移 r=+0.934（fit-rmse 仅 -0.855，属同源互证）。
5. 波段可裁剪且优于全波段：500-800 nm（4.08）> 450-900 nm（1.69）> 全波段 2048 维（1.08）。

**缺点**
1. 最慢：单帧 5.6 s，为纯几何的 3.6 倍（PCA 与逐源点 K 近邻光谱角）。
2. 预处理链最长：需暗/白定标与入射角校正；未校正时边缘波段近于噪声（全波段判别比仅 1.08 即证据）。
3. 数据量与存储最高：每点 2048 波段（约 8 KB），单帧缓存 40 MB。
4. **「少转」退化风险**：恒等变换 SAM = 8.01 度为全表最低，最小化光谱一致性会退化为不旋转解
   （R1 下 C 臂 3/5 帧选中单位阵候选，旋转角仅 23.7/16.3/4.8 度），故光谱项不能单独作为判优依据。
5. **拟合优度类指标上从来不是最优**（R1 下三臂最差；R2 下与 A 持平、低于 B），
   且优势指标（SAM）在 R2 下仅领先 0.04-0.06 度，**不能宣称「多光谱配准更准」**。
6. 参数敏感：lambda、预设波段区间、Delta 均需按对象调整；lambda 过大时位姿向「少转」解漂移。

## 七、共性失效模式

1. 低阈值几何指标不可作成功判据：恒等变换 fit@5mm 0.5133 高于三臂；随机对应 fit@20mm = 0；
   标称开环 fit@20mm 0.8761、rmse 9.14 mm（均低于配准方法）。
2. 转台标称角不可作先验或判据：独立 1-DOF 扫描最优角：60 度 -54 度、120 度 -118 度、180 度 -148 度、
   240 度 +130 度、300 度 0 度；两两传递性误差中位 55.0 度、均值 59.5 度、p90 126.2 度；180 度与 300 度存在结构性歧义。
3. 近似旋转不变是根本难点（近轴结构占 27%-34%，径向距离中位 16.5 mm）。
4. 样本量与随机性限制结论强度：n=5 的符号检验 p 为 0.5-0.97，只能报效应量；
   且 RANSAC 随机采样带来 +-0.001-0.004 的指标波动。

## 八、选型建议

| 场景 | 建议 | 依据 |
|---|---|---|
| 结构丰富、无近似不变/重复结构，只需几何模型 | **A 几何** | 最快最省，R2 下几何指标与 C 持平、互为最近邻最高 |
| 已有彩色点云、只需可视化或粗配准，不需可信度判定 | **B 几何+RGB** | 拟合优度类指标三臂最优、成本最低 |
| 含近轴不变/重复/自相似/同形不同材质，或必须判定「是否配准成功」 | **C 几何+多光谱** | 唯一能算 NDVI、唯一能输出可辨识性判定；消融增益 +0.0215 远超噪声 |
| 算力/存储受限但需物性信息 | **C + 裁剪波段**（如 600-780 nm，452 维） | 波段选择的作用大于维度堆叠（500-800 判别比 4.08 > 全波段 1.08） |
| 要求「绝不静默输出错误位姿」 | **C + 几何门控 + 四层评价** | 光谱最小化会退化为不旋转解（恒等 SAM 8.01 度最低） |

**一句话**：在**配准结果指标**上，「几何+多光谱更好」只有**统一口径 SAM 一处、且幅度在噪声量级**；
多光谱的真实增益体现在**能否构造可辨识性权重**及其消融结果（+0.0215，为噪声的 5-20 倍），
以及**位姿可辨识性判定**这一能力维度上，即多光谱提供的是**可信度与判据**，而非几何精度。

## 九、对专利（创造性）的意义

1. **不应在说明书里写「本方法配准精度更高」**：三臂几何指标差异在运行波动量级内（+-0.001-0.004），
   写精度更高会被审查员或同行用重复性实验驳倒。应写「多光谱提供几何之外的独立判据」。
2. **可写的实证是消融**：可辨识点集 fit@5mm 0.4493 → 0.4709（+0.0215）与位姿偏差 9.4 度 → 6.7 度，
   这是远超噪声的多光谱增益，且直接对应该案的逐点可辨识性加权权项。
3. **反驳「用 RGB 即可」**：RGB 判别比 2.92 < 4.08；缺 800 nm 无法计算 NDVI
   （d=4.01 对最佳可见光代理 3.05），故无法实施逐点权重与可辨识性判定，这是能力性缺失，与精度无关。
4. **反驳「用全部波段即可」**：全波段 2048 维判别比仅 1.08，故预设波段区间是必要技术特征。
5. **支撑「位姿可辨识性判定」权项**：恒等变换 SAM = 8.01 度为全表最低，光谱最小化会退化为不旋转解
   （R1 下 3/5 帧选中单位阵候选），故仅靠光谱优化不足以给出正确位姿，必须以几何门控 + 四层评价 + 可辨识性告警共同输出。

## 十、循环性检验：留出波段交叉验证

**问题**：C 臂的损失函数含 SAM 项，用 SAM 评价 C 即为自证（循环论证）。

**设计**：让**评价用的波段不出现在任何一条臂的优化波段里**。
优化波段：A 无光谱｜B RGB 三通道（490.4/560.3/650.1 nm）｜C 500-800 nm（755 维）；
留出波段：**450-495 nm（115 维）+ 805-900 nm（235 维）= 350 维**，与上述三者均不相交。

### 规则 R1（SAM 参与选解 → 对 C 自证）

| 臂 | fit@5mm↑ | 自评 SAM（该臂优化波段）↓ | **留出 SAM(350 维)**↓ | 留出 450–495 nm↓ | 留出 805–900 nm↓ |
|---|---|---|---|---|---|
| A 几何 | 0.5074 | —（无光谱项） | **20.17°** | 35.43° | 2.00° |
| B 几何+RGB | 0.4913 | 14.35° | **19.66°** | 35.08° | 2.00° |
| C 几何+多光谱 | 0.4653 | 9.04° | **19.68°** | 35.21° | 2.07° |

### 规则 R2（SAM 不参与选解 → 公平）

| 臂 | fit@5mm↑ | 自评 SAM（该臂优化波段）↓ | **留出 SAM(350 维)**↓ | 留出 450–495 nm↓ | 留出 805–900 nm↓ |
|---|---|---|---|---|---|
| A 几何 | 0.5074 | —（无光谱项） | **20.17°** | 35.43° | 2.00° |
| B 几何+RGB | 0.5025 | 15.22° | **20.42°** | 35.31° | 2.04° |
| C 几何+多光谱 | 0.5011 | 10.87° | **20.46°** | 35.36° | 2.02° |

**结论**：
1. **在未被任何方法优化的留出波段上，三臂几乎完全相同**（R1：20.17 / 19.66 / 19.68 度；
   R2：20.17 / 20.42 / 20.46 度），差异 <= 0.8 度，且 **C 不占优、纯几何臂名义最优**。
   即：**C 的谱角优势全部来自「SAM 是其优化目标」，去掉循环后归零。**
2. 「自评 SAM」列（C 9.04 度、B 14.35 度）不能作为方法优劣证据，只能说明各自把目标压到了多少。
3. 留出波段的信息量分布很不均匀：805-900 nm 上三臂都只有约 2.0 度，说明叶片近红外平台的谱形几乎无差异
   （与表 2「纳入近红外后判别比反而下降」一致）；450-495 nm 有 35 度量级的差异但三臂同样无差别。
4. 因此**多光谱的价值不能表述为「配准更准」或「谱角更小」**，只能表述为「提供几何之外的独立判据与
   逐点可辨识性权重」——后者由消融实验（非循环：评价用几何拟合优度与无光谱的 1-DOF 纯旋转物理参考角）
   支撑：可辨识点集 fit@5mm 0.4493 → 0.4709（+0.0215），位姿与独立参考角平均偏差 9.4 度 → 6.7 度；
   全部点口径反而下降 0.0381（须并列报告）。

## 十一、「信息更多 => 不劣」为什么不一定成立，以及怎样才能成立

### 11.1 理论：不劣的保证来自短路，不来自「参数更多」

ResNet 的保证形式是 y = x + f(x) 且 f 可以退化为 0（零初始化/权重衰减），
于是深层网络的**解空间包含**浅层网络的解，训练误差不劣。
搬到配准：浅层 = 纯几何位姿 T_G，残差支路 = 光谱细化 DeltaT，短路 = 允许 DeltaT = 0。
不劣需同时满足三条：

1. **嵌套**：加入光谱后的位姿族必须包含纯几何位姿族；
2. **残差可归零**：存在把光谱项权重降到 0 的路径（本项目 lambda 固定为 1，没有这条路径）；
3. **独立数据选模型**：接受/拒绝残差必须依据不参与拟合的数据判据。

朴素拼接（把光谱块与 FPFH 等权拼成描述子）破坏条件 1：描述子一变，
RANSAC 的互最近邻对应集合就变，优化地形随之改变，可能落到更差的盆地。
另有**维度稀释**的直接证据（第 2 节表 2 判别比）：
RGB 3 通道 2.92 → 500-800 nm 755 维 4.08 → 450-900 nm 1131 维 1.69 → **全波段 2048 维 1.08**。
即：信息维度增加，可用判别力反而下降（冗余与噪声维度被等权计入）。

### 11.2 诊断：损害来自「描述子」，不是来自「损失」

三波段角色分离（互不相交）：优化 500-650 nm｜验证门控 650-800 nm｜测试 450-495 并 805-900 nm。

| 臂 | fit@5mm | fit@10mm | fit@20mm | rmse@20mm | 测试 SAM |
|---|---|---|---|---|---|
| G 纯几何 | 0.4967 | 0.8454 | 0.9833 | 6.97 | 20.29 度 |
| G+MS（描述子+损失，现方案） | 0.4994 | 0.8492 | 0.9847 | 6.86 | 20.32 度 |
| **G+MS 仅描述子（lambda=0）** | 0.4837 | 0.8400 | 0.9820 | 7.02 | 20.24 度 |
| **G+MS 仅损失（描述子保持纯几何）** | 0.4996 | 0.8446 | 0.9835 | 6.93 | 20.10 度 |

只把描述子换成含光谱版本（lambda=0、损失仍是几何 ICP）时 fit@5mm 就已损失 **0.0129**；
而保持纯几何描述子、只把光谱放进损失，则基本无损（+0.0029）。
「描述子+损失」同时含这两部分效果，净值为 +0.0027。
即：**描述子拼接是损害来源；光谱进入到损失里反而是可用的修正项。**
另一个对照：G+RGB+MS（两个光谱块同时进描述子）损失 0.0124，与 lambda=0 的 0.0129 同量级。

### 11.3 噪声标定：臂间差异全部落在同臂运行波动之内

同一臂重复独立运行 3 次（仅 RANSAC 随机采样不同），每次为 5 帧平均：

| 臂 | fit@5mm 标准差（极差） | fit@10mm 标准差 | rmse@20mm 标准差 | yaw_z 标准差（极差） |
|---|---|---|---|---|
| G 纯几何 | 0.0059（0.0141） | 0.0020 | 0.014 mm | **1.30 度（3.18 度）** |
| G+MS（描述子+损失） | 0.0016（0.0034） | 0.0031 | 0.037 mm | 0.32 度（0.76 度） |
| G+MS（仅损失） | 0.0005（0.0011） | 0.0003 | 0.001 mm | **0.05 度（0.10 度）** |

臂间差异与合成标准差之比（fit@5mm / fit@10mm）：
描述子+损失 - G = 0.94 / 1.06；仅损失 - G = 0.86 / 0.73；
描述子+损失 - 仅损失 = 0.37 / 0.79。
**全部比值 <= 1.06 => 均值精度上三臂统计不可区分。**
前几节看到的「多光谱更差」多为噪声，不是方法缺陷。

### 11.4 门控实验：不劣可以保证，但本场景下收益为零

残差架构：以几何解 T_G 为短路，光谱细化只用源点的一半（训练半），门控在另一半（验证半）上判定。

| 门控判据 | 接受率 | Deltafit@5mm | Deltafit@10mm | 说明 |
|---|---|---|---|---|
| 验证波段 SAM（650-800 nm） | 60% | +0.0010 | +0.0023 | 不劣，但在噪声内；120 度帧被误接受（该帧 fit@5 降 0.0175） |
| 留出点 fit@10mm | 80% | -0.0174 | +0.0037 | 判据过粗，误接受，反而劣化 |
| **留出点 fit@5mm（直接跟踪目标指标）** | **0%** | **+0.0000** | **+0.0000** | **门控把所有光谱细化全部拒绝，严格等于纯几何解** |

即：短路加独立判据确实能把「不劣」变成构造性保证（最差情况就是退回 T_G），
但本对象上门控退化为「全部拒绝」——在留出几何数据上，光谱细化**从未证明自己不劣于几何解**。
这也说明**均值精度不是多光谱的用武之地**：几何已把 fit@20mm 做到 0.983，
剩余误差来自叶片非刚性、2.5 mm 量化、7x8 度小视场，属误差地板，不是信息量不足。

### 11.5 多光谱真正稳健的收益：解的稳定性（新发现）

11.3 表最后一列：**yaw_z 标准差从纯几何的 1.30 度降到 0.32 度（描述子+损失）
与 0.05 度（仅损失）**，fit@5mm 标准差从 0.0059 降到 0.0005。
光谱项把位姿解**拉向一个更稳定的盆地**，方差降低约 29 倍。
该指标是位姿自身的散布（非循环，不含 SAM 优化），方向与理论一致：约束越多，解方差越小。

### 11.6 实践含义

1. **架构建议**：几何解作恒等短路；光谱只进入位姿细化与判据，不进入描述子；
   用留出的几何数据与波段的「不劣」检验决定是否接受残差，不通过则退回几何位姿。
   这正好对应当案权项「逐点可辨识性加权 + 位姿可辨识性判定」的工程实现。
2. **可宣称**：稳定性与可重复性提升（yaw_z 标准差 1.30 度 -> 0.05 度 至 0.32 度）；
   可辨识性判定能力；NDVI 可算性（RGB 不可算）。
3. **不可宣称**：位姿精度更高。臂间差异在自身运行波动（fit@5mm 标准差 0.0059）之内。
4. **要证明「多光谱更准」必须换场景**：几何可辨识性不足时（只留叶片、去花盆与主干、
   对称/重复结构、同形不同材质），门控接受率才会大于零，优势才有发挥空间。
